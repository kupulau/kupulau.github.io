벡터 데이터베이스(Vector Database)는 고차원 벡터 데이터를 효율적으로 저장하고 검색할 수 있도록 설계된 데이터베이스이다. 특히, **유사한 데이터를 빠르게 찾는 Nearest Neighbor Search**를 최적화하는 기능이 핵심이다.

기존의 관계형 DB(SQL 등)는 정확한 값을 검색하는데 최적화되어 있는데, 많은 AI 응용에서는 **유사한** 값을 찾는 검색이 필요하다. 예를 들어, "강아지 훈련 방법"을 검색했을 때, 보다 풍부한 검색 결과 반환을 위해서는 정확히 "강아지 훈련 방법"이라는 구절이 있는 자료만을 반환하기 보다 의미가 유사한 "반려견 교육 요령", "강아지 행동 교정" 등의 단어가 포함된 자료들까지 반환하는 것이 더 좋을 것이다. 따라서 벡터 데이터베이스는 유사성 기반 검색에 최적화되어 있고, 텍스트/이미지 검색, 추천 시스템 등에 활용된다. 

<br>

### 주요 기술
- 벡터 임베딩 (Vector Embedding) : 텍스트, 이미지, 오디오 데이터를 숫자 벡터로 변환
- 유사도 측정 : Cosine similarity, Euclidean distance, dot product 등으로 벡터 간의 거리를 측정하여 유사도 계산
- 인덱싱
  - FAISS (Facebook AI Similarity Search)
  - HNSW (Hierarchical Navigable Small World) : 그래프 기반 빠른 탐색
  - Annoy (Approximate Nearest Neighbors Oh Yeah) : 트리 기반 탐색
  
<br>

### 활용 사례
- 자연어 검색 (RAG)
- 추천 시스템
- 이미지 검색
- 이상 탐지

<br>

### 주요 벡터 DB 종류
|벡터DB|특징|
|:--:|:--:|
|FAISS|Meta가 개발한 대규모 벡터 검색에 최적화된 DB|
|Pinecone|클라우드 기반 벡터 DB, 빠르고 확장 가능|
|Weaviate|메타데이터 필터링 지원, AI 친화적|
|Milvus|오픈 소스 DB, 대용량 데이터 지원|
|Chroma|간단한 설치, AI 애플리케이션 개발에 적합|
