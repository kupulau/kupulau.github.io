### 라이브러리 import
```python
import pandas as pd
import pydataset

import sqlite3
```

이 때 사용하고자 하는 DBMS에 따라 다른 파이썬 라이브러리를 설치/import하면 된다. 
여기서는 파이썬에 내장된 SQLite 라이브러리인 `sqlite3`를 사용해보자.

#### DBMS별 파이썬 라이브러리

|DBMS|	주요 라이브러리|	설치 명령	|사용 예|
|:--:|:--:|:--:|:--:|
|SQLite|	`sqlite3`| 없음 (파이썬 내장)|	`import sqlite3`|
|MySQL	|`mysql-connector-python` or `PyMySQL` or `MySQLdb`|	`pip install mysql-connector-python`|	`import mysql.connector`|
|PostgreSQL|	`psycopg2` or `asyncpg`	|`pip install psycopg2`|	`import psycopg2`|
|Oracle|	`cx_Oracle`|	`pip install cx_Oracle`	|`import cx_Oracle`|
|SQL Server|	`pyodbc` or `pymssql`|	`pip install pyodbc`|	`import pyodbc`|

### 외부 DB 접속
#### .env 파일 작성 & 로드

외부 DB 접속 정보는 민감한 정보이므로 먼저 `.env` 파일을 작성하여 그 안에 접속 정보를 담자. 

```
DB_HOST=db_server_ip
DB_USER=username
DB_PASSWORD=password
DB_NAME=tbl_name
DB_PORT=portnumber
```

그리고 아래와 같이 .env에서 접속 정보를 로드해준다.

```python
import os
from dotenv import load_dotenv

load_dotenv()   # 작업 중인 디렉토리에 .env가 있는 경우
#load_dotenv(dotenv_path='/path/to/my/env/.env').  # 별도의 .env 위치를 명시할 때
```

<br>

#### pymysql 연결 예시


```python
import pymysql

connection = pymysql.connect(
    host=os.getenv("DB_HOST"),       # '127.0.0.1' or your db server IP
    user=os.getenv("DB_USER"),       # 'username'
    password=os.getenv("DB_PASSWORD"),   # 'password'
    database=os.getenv("DB_NAME"),   
    port=int(os.getenv("DB_PORT"))    # 정수형으로 바꾸어야 함
)

try:
    with connection.cursor() as cursor:
        sql = "SELECT * FROM tbl1;"
        cursor.execute(sql)
        result = cursor.fetchall()
        for row in result:
            print(row)
finally:
    connection.close()
```

<br>

### 쿼리 결과 DataFrame으로 변환하기

`cursor.fetchall()`로 가져온 데이터는 보통 리스트의 튜플 형태로 반환된다. 따라서 아래 코드를 이용하면 보다 깔끔하게 DataFrame 형식으로 변환해서 볼 수 있다.

```python
import pandas as pd

# description에서 컬럼 이름 추출
columns = [desc[0] for desc in cursor.description]

df = pd.DataFrame(result, columns=columns)
```

### 다른 라이브러리 코드 예시
#### PostgreSQL
```python
import psycopg2

connection = psycopg2.connect(
    host='DB_HOST',       
    user='DB_USER',       
    password='DB_PASS',   
    dbname='DB_NAME'    
)

try:
    with connection.cursor() as cursor:
        sql = "SELECT * FROM subDB2.tbl3;"
        cursor.execute(sql)
        result = cursor.fetchall()
        for row in result:
            print(row)
finally:
    connection.close()
```

#### SQLAlchemy

```python
from sqlalchemy import create_engine

# MySQL 예시
db_url = "mysql+pymysql://DB_USER:DB_PASS@DB_HOST/DB_NAME"

# PostgreSQL 예시
# db_url = "postgresql+psycopg2://DB_USER:DB_PASS@DB_HOST/DB_NAME"

engine = create_engine(db_url)
with engine.connect() as connection:
    result = connection.execute("SELECT * FROM tbl3;")
    for row in result:
        print(row)
```
