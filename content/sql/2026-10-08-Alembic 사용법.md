Alembic은 파이썬에서 SQLAlchemy 등과 함께 사용되는 데이터베이스 형상 관리(마이그레이션) 툴이다. 테이블 생성, 컬럼 추가/수정/삭제 등 데이터베이스 스키마(구조) 변경 이력을 파이썬 코드로 버전 관리할 수 있게 해준다.
SQL문을 직접 작성하지 않고도 변경 사항을 자동으로 감지(autogenerate)하여 마이그레이션 스크립트를 생성하며, 여러 개발 환경이나 프로덕션 서버 간의 DB 구조 동기화 및 롤백을 쉽게 처리할 수 있다. 주로 Flask나 FastAPI 같은 프레임워크 프로젝트에서 자주 쓰인다. 


## 설치/초기화

```bash
pip install alembic sqlalchemy "psycopg[binary]"
alembic init migrations
```

위의 명령어를 실행하면 기본 구조가 생긴다.

```bash
alembic.ini     # 설정 파일
migrations/
	env.py           # 마이그레이션 실행 환경 (DB 연결, 메타데이터 설정)
	script.py.mako       # 새 마이그레이션 파일 템플릿 
	versions/        # 마이그레이션 파일들이 쌓이는 곳
```


## DB 접속 정보 설정

`.env` 파일을 만들고 그 안에 접속 정보를 작성한다. (git 등에 업로드되지 않도록 주의!!!)

```
DATABASE_URL=postgresql+psycopg://postgres:localpass@localhost:5432/analytics

```

그리고 `env.py` 상단에 `.env`의 환경 변수를 읽어오도록 코드를 추가한다.  

```python
import os
from dotenv import load_dotenv

load_dotenv()

config = context.config
config.set_main_option("sqlalchemy.url", os.getenv("DATABASE_URL"))
```

 

## 모델 연결

SQLAlchemy 모델을 정의하고, `env.py`에서 그 메타데이터를 알려줘야 `autogenerate`가 비교할 대상을 알 수 있다. 

- `models.py`
```python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

class Base(DeclarativeBase):
    pass

class DimProduct(Base):
    __tablename__ = "dim_product"
    __table_args__ = {"schema": "dw"}
    product_key: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str]
    category: Mapped[str]
```

- `env.py`
```python
from models import Base
target_metadata = Base.metadata
```


## 마이그레이션 만들기

마이그레이션을 만드는 방법은 크게 2가지가 있는데, 첫번째는 빈 파일을 만들고 직접 작성하는 방식이다. 스키마 생성과 같이 autogenerate가 못하는 작업에 사용한다.

```bash
alembic revision -m "create schemas"
```

위의 명령어로 생성된 `versions/xxxx_create_schemas.py`에 `upgrade()`와 `downgrade()`를 작성한다. 

```python
def upgrade():
    for s in ("staging", "dw", "mart"):
        op.execute(f"CREATE SCHEMA IF NOT EXISTS {s}")

def downgrade():
    for s in ("mart", "dw", "staging"):
        op.execute(f"DROP SCHEMA IF EXISTS {s} CASCADE")
```

두 번째 방법은 모델을 수정한 뒤 DB와의 차이를 자동으로 생성하는 방식이다. 아래 명령어로 생성된 파일은 반드시 직접 열어서 검토하자. 의도와 다르게 만들어지는 경우가 생길 수 있다. 

```bash
alembic revision --autogenerate -m "add dim_product"
```



## 적용/되돌리기

```bash
alembic upgrade head      # 최신 버전 적용
alembic upgrade +1        # 한 단계만 적용
alembic downgrade -1      # 한 단계 되돌리기
alembic downgrade base    # 가장 처음 버전으로 되돌리기
```


## 상태 확인
```bash
alembic current      # 현재 DB 버전 확인
alembic history      # 전체 마이그레이션 이력
alembic check        # 모델과 DB 사이에 아직 마이그레이션이 되지 않은 차이가 있는지 체크
```
