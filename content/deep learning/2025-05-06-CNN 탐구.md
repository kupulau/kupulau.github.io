CNN(**C**onvolutional **N**eural **N**etwork)은 딥러닝을 위한 신경망 구조이다. CNN을 이용하면 이미지를 직접적으로 학습할 수 있다. 

### Fully-Connected Neural Network

![](https://velog.velcdn.com/images/kupulau/post/a219c254-34e0-449a-a66e-491aec19d404/image.png)

Fully-Connected Neural Network(FCNN)는 답러닝의 가장 기본적인 구조 중 하나로, 각 레이어의 모든 뉴런이 이전 레이어의 모든 뉴런과 연결되어 있는 구조를 가진 신경망이다. 이러한 연결 방식은 입력 데이터의 모든 특징을 고려하여 학습할 수 있게 해준다. 

FCNN은 input layer, hidden layer, output layer로 구성되어 있다.
- 입력층 (Input Layer) : 모델에 입력되는 데이터의 특징(feature)들을 나타낸다. 
ex) 이미지의 경우 각 픽셀 값
- 은닉층 (Hidden Layers) : 입력층과 출력층 사이에 위치하며, 각 뉴런은 이전 층의 모든 뉴런과 연결되어 있다. 이 층들은 입력 데이터를 변환하여 더 높은 수준의 특징을 추출한다.
- 출력층 (Output Layer) : 모델의 최종 예측 결과를 출력한다. 분류 문제의 경우 각 클래스에 대한 확률을 나타낼 수 있습니다.

FCNN에서 각 뉴런은 이전 층의 모든 뉴런으로부터 입력을 받아 가중치를 곱하고 bias를 더한 후 활성화 함수를 통해 출력을 생성한다.

FCNN은 모든 뉴런이 연결되어 있기 때문에 수백만 개의 파라미터가 생기고, 이때문에 학습이 느리고, overfitting에 취약하며 연산 자원을 많이 소모한다. 게다가 이미지를 학습할 때 각 픽셀을 독립적인 feature로 간주하기 때문에 이웃한 픽셀과의 공간적 패턴을 학습할 수 없다. 또한, 위치 정보를 고정된 입력으로 처리하여 객체의 위치가 바뀌면 이를 인지할 수 없게 된다. 이를 보완하기 위해 CNN 구조가 개발되었다.

#### ❓ FCNN와 Multilayer Perceptron (MLP)
FCNN과 MLP는 거의 같지만 약간의 차이가 있다. 둘 다 다층 구조의 완전 연결 신경망으로, 입력층 → 은닉층 → 출력층으로 구성되어 있지만
- FCNN : 모든 뉴런이 완전 연결된 구조를 강조한 표현으로, CNN, RNN과 대비되는 개념이다.
- MLP : 하나 이상의 은닉층을 가진 퍼셉트론 구조로, 보통 비활성화 함수가 포함된 개념이다. FCNN의 하위 개념이다.
따라서 모든 MLP는 FCNN이지만, 모든 FCNN이 MLP인 것은 아니다. (활성화 함수 없이 단순 선형 구조만 있는 FCNN이라면 MLP라 할 수 없다.)

그럼에도 불구하고 대체적으로는 거의 같은 개념으로 구분없이 사용한다고 한다.

### Convolutional Neural Network
![](https://velog.velcdn.com/images/kupulau/post/c96db7df-7bf6-4310-9dae-205d33be86bf/image.png)


local Receptive fields
CNN에서는 입력 계층 뉴런의 작은 영역이 합쳐져 은닉 계층의 뉴런과 연결된다. 연결하여 입력 계층에서 은닉 계층 뉴런으로의 feature map을 만든다. 이 과정에서 convolution 연산을 사용한다. 


shared weights and biases
CNN은 가중치와 편향 값이 주어진 계층의 모든 은닉 뉴런에 대해 동일하다. 이는 모든 은닉 뉴런이 영상의 서로 다른 영역에서 경계나 블롭과 같은 특징을 감지한다는 것을 의미한다. 이는 신경망이 영상 내 객체의 평행 이동에 대해 잘 대응할 수 있기 때문에 객체가 어느 위치에 있던지 상관없이 잘 인식할 수 있다.


activation and pooling

활성화 단계에서는 각 뉴런의 출력을 활성화 함수를 사용하여 변환한다.

pooling은 작은 영역의 출력을 단일 출력값으로 응축시켜 특징 맵의 차원을 축소시킨다. 이를 통해 후속 계층을 단순화할 수 있으며 모델이 학습해야 할 파라미터 수를 줄일 수 있다. 




CNN의 각 계층은 이미지에서 서로 다른 특징을 검출하도록 학습된다. 이 특징 맵에서 우리는 모든 은닉 계층이 학습된 영상 특징의 복잡성을 증가시킨다는 것을 알 수 있다. 첫 번째 은닉 계층은 경계를 검출하는 방법을 학습하고 마지막 계층은 더 복잡한 형태를 검출하는 방법을 학습할 수 있다. 


### Pytorch로 구현하기 & 구조 뜯어보기
![](https://velog.velcdn.com/images/kupulau/post/f23aa179-9da6-4370-b390-a810167599fb/image.png)

MNIST 분류를 위한 CNN 코드를 구현해보자. MNIST는 28x28 크기의 손글씨 숫자 이미지이다. 

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CNN(nn.Module):
	def __init__(self, num_label=10):
    	super(CNN, self).__init__()
        self.conv1 = nn.Sequential(
        	nn.Conv2d(in_channels=1, out_channels=16, kernel_size=3),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=1)
        )
        self.conv2 = nn.Sequential(
        	nn.Conv2d(in_channels=16, out_channels=2, kernel_size=3),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=1)
        )
        self.classifier = nn.Sequential(
        	nn.Flatten(1, -1),
            nn.Linear(7*7*32*32),
            nn.ReLU(),
            nn.Dropout(p=0.3)
            nn.Linear(32, num_label)
        )
        
	def forward(self, x):
    	x = self.conv1(x)
        x = self.conv2(x)
        x = self.classifier(x)
        return x
```

#### Conv2d
![](https://velog.velcdn.com/images/kupulau/post/388c385e-6e53-4dff-b6da-5add4c23cfb9/image.gif)

가장 먼저 `self.conv1`에서 convolution 연산이 일어난다. convolution 연산은 위의 애니메이션에서 어떻게 진행되는지 확인할 수 있다. input 행렬과 필터를 매칭되는 칸끼리 곱하고 더해서 각 칸의 값을 계산한다. 필터는 가중치가 담긴 행렬이기 때문에 커널이라고도 불린다. 애니메이션의 가운데 3 x 3 행렬이 바로 커널이다.
convolution 연산을 거친 후의 출력 크기(height, width)는 다음과 같이 계산할 수 있다.

>$H_{out} = \frac{H_{in}+2P_h-K_h}{S_h}+1$
>
$W_{out} = \frac{W_{in}+2P_w-K_w}{S_w}+1$
> 
where $P_h, P_w$ = (height, width 방향의) padding
	 $K_h, K_w$ = (height, width 방향의) kernel size
	 $S_h, S_w$ = (height, width 방향의) stride

#### padding
입력 이미지의 가장자리에 0(혹은 다른 값)을 덧붙여서 출력 크기를 조절하거나 정보 손실을 줄이는 것이다. padding을 이용하면 가장자리 정보도 잘 반영하고 출력 크기를 입력과 같게 유지할 수 있다.

#### stride
커널이 한 번에 몇 칸씩 이동할지 결정하는 값이다. 위의 애니메이션에서는 stride=1씩 이동하고 있다. stride를 늘리면 input matrix를 sparse하게 스캔하면서 연산량이 감소하고 학습 속도가 빨라지며 출력 크기가 줄어든다.

<br>

위의 계산식에 따르면, `self.conv1` 내의 `nn.Conv2d(in_channels=1, out_channels=16, kernel_size=3)`이 실행되며 1 x 28 x 28 이미지가 16 x 26 x 26 이미지가 된다. 이는 이 convolutional layer이 입력 이미지에서 16개의 feature를 학습하도록 3 x 3 커널을 16개 사용하겠다는 의미이다. 각각의 커널은 입력 이미지에서 다른 종류의 패턴을 감지하고 학습한다. 예를 들어 커널 1은 수직선 감지, 커널 2는 수평선 감지, .... 다시 말하면 16개의 26 x 26 feature map을 생성한 것이다. `out_channels` 값은 임의로 정하는 값이고, 일반적으로는 32, 64, 128, ...처럼 점점 늘리는 구조를 사용한다.
