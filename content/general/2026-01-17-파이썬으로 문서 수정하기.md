Canva, Adobe 등을 활용하면 이미지를 pdf로 변환할 수 있지만 파이썬 코드를 활용해서도 여러 파일 형 간의 변환 작업을 간단히 할 수 있다. 


## image to pdf

```python
from PIL import Image
import glob
from pathlib import Path

# change here
input_img_path = "img*.jpg"
output_pdf_path = "img.pdf"

input_img_files = glob.glob(input_img_path)

images = []
for img_path in input_img_files:
    img_path = Path(img_path)
    img = Image.open(img_path)
    
    # RGBA 이미지는 RGB로 변환 (투명도 제거)
    if img.mode == 'RGBA':
        # 흰색 배경에 합성
        background = Image.new('RGB', img.size, (255, 255, 255))
        background.paste(img, mask=img.split()[3])  # 알파 채널을 마스크로 사용
        img = background
    elif img.mode != 'RGB':
        img = img.convert('RGB')
    
    images.append(img)

    images[0].save(
        output_pdf_path,
        "PDF",
        resolution=100.0,
        save_all=True,
        append_images=images[1:] if len(images) > 1 else []
    )
```

## pdf to docx

`pdf2docx` 라이브러리를 이용하면 PDF를 Word 문서로 손쉽게 변환할 수 있다.
`pdf2docx`는 내부적으로 PyMuPDF를 사용하여 글자 및 표, 이미지가 어느 위치에 있는지 읽어와 재구성한다.

`pip install pdf2docx`를 통해 라이브러리를 설치할 수 있다. 

```python
from pdf2docx import parse

pdf_file = 'filename.pdf'   # 변환할 PDF 파일 경로
docx_file = 'filename.docx' # 저장할 Word 파일 경로

parse(pdf_file, docx_file)
```

## pdf 수정

pdf 파일에서 일부 페이지를 제외하고 새로운 pdf 파일을 만들고 싶을 때가 있다. 그럴 때는 아래 코드를 활용하면 된다.


```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("file.pdf")   # 원본 PDF
writer = PdfWriter()

# 남기고 싶은 페이지 번호 (사람이 세는 1부터의 번호)
keep_pages = [1, 6, 7, 8]

for num in keep_pages:
    writer.add_page(reader.pages[num - 1])  # 코드 인덱스는 0부터라 -1

with open("output.pdf", "wb") as f:
    writer.write(f)

print("완료! output.pdf 생성됨")
```
