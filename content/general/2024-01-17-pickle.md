pickle은 파이썬에서 사용하는 딕셔너리, 리스트, 클래스 등의 자료형을 변환 없이 그대로 파일로 저장하고 이를 불러올 때 사용하는 모듈이다.

#### 설치
```
pip install pickle
```

#### 사용법
```python
import pickle
```
- 리스트를 피클 데이터로 저장하기
```python
list1 = ['a', 'b', 'c']
with open('list1.pickle', 'wb') as pickle_filename:
	pickle.dump(list1, pickle_filename)
# 주의! pickle_filename은 그대로 쓰는 것이다.
```
- 저장한 피클 데이터 리스트로 다시 읽어오기
```python
with open('list1.pickle', 'rb') as pickle_filename:
	list2 = pickle.load(pickle_filename)
# 마찬가지로 pickle_filename을 그대로 쓴다.
# list2에는 list1.pickle의 정보가 든 리스트가 다시 저장된다.
```
