아이폰으로 찍은 사진은 별도로 설정을 바꾸지 않는 이상 heic 형식으로 저장된다. (카메라 설정에서 기본 저장 형식을 jpeg로 변경 가능) heic 형식은 고화질을 유지하면서 파일 크기를 크게 줄이기 위해 만들어진 최신 이미지 포맷이다. 다만 호환되지 않는 곳이 많은 파일 형식이라 보다 호환이 편한 jpg로 변환하는 방법을 알아보고자 한다.

### 파이썬 코드로 변환
#### 라이브러리 설치
`pip install pillow pillow-heif`

#### 한 장 변환
```python
from PIL import Image
import pillow_heif

# HEIC 지원 등록
pillow_heif.register_heif_opener()

input_path = "input.heic"
output_path = "output.jpg"

img = Image.open(input_path)
rgb_img = img.convert("RGB")   # JPG는 RGB 필요
rgb_img.save(output_path, "JPEG")

print("변환 완료")
```

#### 여러 장 변환
```python
import os
from PIL import Image
import pillow_heif

pillow_heif.register_heif_opener()

input_dir = "heic_files"
output_dir = "jpg_files"

os.makedirs(output_dir, exist_ok=True)

for file in os.listdir(input_dir):
    if file.lower().endswith(".heic"):
        input_path = os.path.join(input_dir, file)
        output_path = os.path.join(
            output_dir,
            os.path.splitext(file)[0] + ".jpg"
        )

        img = Image.open(input_path)
        img.convert("RGB").save(output_path, "JPEG")

        print(f"converted: {file}")

print("전체 변환 완료")
```

### 맥에서 변환
맥에서는 터미널에서 아래의 한 줄 명령어로 간단하게 변환할 수도 있다. 
`sips -s format jpeg input.heic --out output.jpg`
