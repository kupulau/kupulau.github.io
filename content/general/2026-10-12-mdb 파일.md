`.mdb` 파일은 마이크로소프트의 데스크톱 관계형 데이터베이스 프로그램인 Microsoft Access 2003 (및 이전 버전)에서 생성/사용하는 데이터베이스 파일 형식이다. 

## 주요 특징

- **데이터 구조 저장**: 테이블, 쿼리, 폼, 보고서, 매크로 등 데이터베이스의 전체 구조와 데이터를 하나의 파일에 담고 있다. 
- **Jet 데이터베이스 엔진**: 데이터를 저장하고 검색하기 위해 마이크로소프트의 Jet 엔진을 사용한다.
- **최신 형식과의 차이**: Access 2007 이후부터는 기본 형식이 `.accdb`로 변경되었음
- **장점** : 소규모 환경에서 구축이 쉽고 SQL을 지원한다.
- **단점** : 다중 사용자 접근 시 데이터 충돌이 발생할 수 있고 원격 연결이 취약하다.

## 파일 여는 방법

Microsoft Access를 이용해 열고 편집할 수 있지만, 요즘은 Access를 잘 이용하지 않으므로 파이썬으로 열어서 csv 파일로 변환해보자.

### Windows
Windows에는 보통 “Microsoft Access Driver”가 설치되어 있다. 만약 설치되어 있지 않다면, Microsoft Access Database Engine(재배포 패키지)을 설치하여 쓸 수 있다. 이때 파이썬과 드라이버의 비트 수(32/64비트)가 같아야 한다.

```python
import pyodbc
import pandas as pd

conn_str = (
    r"DRIVER={Microsoft Access Driver (*.mdb, *.accdb)};"
    r"DBQ=C:\path\to\file.mdb;"
)
conn = pyodbc.connect(conn_str)

# 테이블 목록 확인
cursor = conn.cursor()
for row in cursor.tables(tableType="TABLE"):
    print(row.table_name)

# 테이블을 DataFrame으로 읽기
df = pd.read_sql("SELECT * FROM 테이블이름", conn)
conn.close()
```

### macOS / Linux

우선 `sudo apt install mdbtools` 또는 `brew install mdbtools` 로 mdbtools를 설치한다. mdbtools를 이용해 파일을 읽고, csv로 내보내면 된다.

```python
import subprocess, io
import pandas as pd

path = "file.mdb"
tables = subprocess.check_output(["mdb-tables", "-1", path]).decode().split("\n")
tables = [t for t in tables if t]

csv = subprocess.check_output(["mdb-export", path, tables[0]]).decode()
df = pd.read_csv(io.StringIO(csv))
```


### 읽기만 필요할 때

파이썬 라이브러리를 이용하여 읽기만 할 수도 있다. `pip install access-parser`로 설치하면 된다.

```python
from access_parser import AccessParser 

db = AccessParser("file.mdb") 
print(db.catalog) # 테이블 목록 
table = db.parse_table("테이블이름") # dict 형태로 반환
```
