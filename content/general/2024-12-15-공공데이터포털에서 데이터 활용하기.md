데이터는 여러 방법으로 수집할 수 있겠지만, [공공데이터포털](https://www.data.go.kr)에서 데이터를 가져와서 활용할 수도 있다! 공공데이터포털은 대한민국 정부에서 제공하는 공공 데이터의 통합 제공 및 개방 플랫폼이다. 행정, 기상, 교통, 환경, 보건 등 여러 분야의 데이터를 csv, json, xml 등 다양한 형식으로 다운받을 수 있고 API로 활용할 수도 있다.

### 회원 가입
공공 데이터를 활용하려면 우선 공공 데이터 포털에 가입되어 있어야 한다. 가입한 적이 없다면 먼저 회원가입을 하도록 하자.

### API 인증키 발급
단순히 업로드 되어 있는 데이터 파일을 다운 받는다면 인증키를 발급받을 필요가 없지만, API를 활용하려면 API 인증키 발급이 필요하다. API 인증키는 따로 발급 신청을 하는 것이 아니라, 필요한 특정 데이터 활용 신청을 함으로써 발급 받게 된다. 
나의 경우 "기상청 단기예보 ((구) 동네예보) 조회서비스" API 활용이 필요하므로, 우선 공공데이터포털에서 기상청 단기예보를 검색하여 해당 페이지에 들어왔다.

![](https://velog.velcdn.com/images/kupulau/post/a2415ff5-0e69-442c-bf8a-06c22264f846/image.png)

우측 상단의 활용신청 버튼을 클릭하면 활용 목적, 상세기능정보 선택, 라이선스 표시 등의 항목이 나오는데 자신의 목적에 맞게 내용을 기입 및 선택하고 활용신청을 하면 즉시 인증키가 발급된다.

### API 인증키 발급 확인
발급된 API 인증키를 확인하려면 `마이페이지` > `데이터 활용` > `OpenAPI` > `인증키 발급현황` 에서 확인할 수 있다. 

**⚠️ API 인증키는 개인정보이므로 외부에 노출되지 않도록 유의한다**
