## 버블 정렬 
![](https://velog.velcdn.com/images/kupulau/post/7686a1e6-2e9e-48a0-921d-86b1d4bdd06e/image.gif)

버블 정렬(Bubble sort)은 배열의 처음부터 끝까지 탐색을 하면서 i번째와 i+1번째 칸을 비교하여 swap을 하는 방식의 정렬 알고리즘이다. 

버블 정렬을 파이썬으로 구현하면 아래 코드와 같다.

```python
def BubbleSort(list1):
	for i in range(len(list1)-1, 0, -1):
    	for j in range(i):
        	if list1[j] > list1[j+1]:
            	temp = list1[j]
                list1[j] = list1[j+1]
                list1[j+1] = temp
```



## 선택 정렬
![](https://velog.velcdn.com/images/kupulau/post/a67ec83a-775c-43f0-87bf-3a37c5513f83/image.gif)

선택 정렬(Selection sort)은 주어진 배열 중에 최소값을 찾아 정렬되지 않은 배열의 맨 앞 값과 자리를 바꾸어나가는 정렬 알고리즘이다. 배열의 맨 앞부터 차례로 정렬이 된다. 

선택 정렬을 파이썬으로 구현하면 아래 코드와 같다.
```python
def SelectionSort(list1):
    for i in range(len(list1)-1, 0, -1):
        max_position = 0
        for loc in range(1, i+1):
            if list1[loc] > list1[max_position]:
                max_position = loc
        temp = list1[i]
        list1[loc] = list1[max_position]
        list1[max_position] = temp
```



## 삽입 정렬
![](https://velog.velcdn.com/images/kupulau/post/6a3f8aaf-355b-4ddd-a677-bd19fd40271d/image.gif)

삽입 정렬(Insertion Sort)은 배열을 정렬된 부분과 정렬되지 않은 부분으로 나누고 정렬되지 않은 요소를 하나씩 꺼내 적절한 위치에 삽입하는 정렬 알고리즘이다. 예를 들어 \[5, 3, 8, 1, 2]와 같은 배열이 있다면 첫 번째 원소 5는 이미 정렬된 상태로 간주하고, 두 번째 원소부터 "적절한" 위치에 삽입하는 것이다. 3이 5보다 작으므로, 5 앞으로 3을 이동시켜 \[3, 5, 8, 1, 2]로 만들고 다음 원소들에 대해서도 같은 작업을 반복한다. 

삽입 정렬을 파이썬으로 구현하면 아래 코드와 같다.
```python
def InsertionSort(list1):
    for i in range(1, len(list1)):
        while 0 < i and list1[i] < list1[i-1]:
            list1[i], list1[i-1] = list1[i-1], list1[i]
            i -= 1
```


## 합병 정렬
![](https://velog.velcdn.com/images/kupulau/post/15c89efe-527d-42b2-ad3e-7c08bd7c1f50/image.gif)

합병 정렬(Merge sort)은 배열을 잘게 쪼갠 뒤 둘 씩 크기를 비교해 정렬하고 분리된 리스트를 재귀적으로 합쳐서 정렬을 완성하는 알고리즘이다. 분할된 배열을 저장할 공간이 필요하기 때문에 메모리 소모량이 큰 편이다. 문제를 분리하고 각각을 해결한 후 다시 합치는 divide & conquer 방식을 사용한다.




## Tim sort
Tim sort는 삽입 정렬과 합병 정렬을 조합한 정렬 알고리즘으로, 현실 세계의 데이터가 어느 정도는 정렬된 상태로 배열되어 있다는 가정을 바탕으로 배열을 작은 덩어리로 잘라 각각의 덩어리를 삽입 정렬로 정렬한 뒤 합병 정렬을 하면 더 빠르게 할 수 있을 것으로 기대하여 개발된 알고리즘이다.

파이썬에서 정렬할 때 사용하는 `sorted()`와 `.sort()`가 Tim sort를 활용하여 $O(N\, log\, N)$의 시간 복잡도가 소요된다. 




## 정리

|정렬 알고리즘|시간 복잡도|
|:--:|:--:|
|버블 정렬|$O(N^2)$|
|선택 정렬|$O(N^2)$|
|삽입 정렬|$O(N^2)$ (평균) / $O(N)$ (최선)|
|합병 정렬|$O(N\, log \,N)$|
|Tim sort|$O(N\, log \,N)$ (평균) / $O(N)$ (최선)|
