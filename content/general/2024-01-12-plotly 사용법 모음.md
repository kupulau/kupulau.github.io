현직자들 사이에서 matplotlib은 꽤 낡은 라이브러리 취급되는 것 같다(...)
plotly는 인터랙티브한 시각화가 가능한 라이브러리이고, pandas data frame과의 호환도 좋으니 plotly를 사용하는 연습을 해보려고 한다.

### 설치
```bash
pip install plotly chart_studio
pip install cufflinks
```

### 사용법
```python
import chart_studio.plotly as py
import cufflinks as cf
cf.go_offline(connected=True)
```

** cf.go_offline(connected=True)는 오프라인에서도 사용할 수 있도록 하는 코드이다. 꼭 필요한 옵션은 아니지만, 옵션을 사용하지 않았을 경우  
```
RequestError: Authentication credentials were not provided.
```
와 같이 인증키 등을 요청하는 귀찮은 문제가 생길 수 있으므로 되도록 옵션을 쓰도록 한다.

```python
import pandas as pd

df = pd.read_csv('df.csv')  # 분석할 데이터가 든 pandas data frame 읽어오기
```

- 어떤 그래프를 그릴 수 있는지 확인해보기
```python
cf.help()
# bar, box, bubble, bubble3d, candle, cahoroplet, distplot, heatmap, histogram, ohlc, pie, ratio, scatter, scatter3d, scattergeo, spread, surface , violin
```

- 특정 그래프에 대한 설명 확인하기
```python
cf.help('histogram')
```

- 그래프 크기 조정하기
```python
df.iplot(dimensions=(x,y))
```

- heat map 그리기
```python
df.corr().iplot(kind='heatmap')
```

- 막대 그래프 그리기
```python
df.iplot(kind='bar')
# possible option : barmode='stack'
```

- 히스토그램 그리기
```python
df.iplot(kind='histogram', histfunc='count', bins=(0, 20, 1), bargap=0.1)
```

- 파이 차트 그리기
```python
df.iplot(kind='pie', labels='tag', values='index')
```

- subplot 그리기
```python
from plotly.subplots import make_subplots
import plotly.graph_objects as go

# 아래는 jupyter notebook에서 보일 수 있도록 설정
import plotly.offline as pyo 
pyo.init_notebook_mode()   

fig = make_subplots(rows=1, cols=3, specs=[[{"type": "domain"}, {"type": "domain"}, {"type": "domain"}]], subplot_titles=['Fig 1.', 'Fig 2.', 'Fig 3.'])
fig.add_trace(go.Pie(labels=df.index, values=df[1]), row=1, col=1)
fig.add_trace(go.Pie(labels=df.index, values=df[2]), row=1, col=2)
fig.add_trace(go.Pie(labels=df.index, values=df[3]), row=1, col=3)
#  위 코드를 통해 1열 3행의 pie chart가 subplot으로 하나의 그림으로 완성됨
```

- violin plot 그리기
violin plot은 일변량, 연속형 데이터의 분포를 설명하기 위해 사용되는 그래프이다. 
```python
import plotly.express as px
fig = px.violin(df, y='col1', color='col2', violinmode='overlay')
```
- scatterplot matrix
**s**catter**plo**t **m**atrices (splom) 은 데이터의 다양한 변수간의 관계를 scatter plot으로 나타낸 것이다. heat map과 같이 변수와 변수 간의 상관 관계를 보기 좋은데, heat map이 단순히 상관 관계의 강도만 보는 것이라면 splom은 변수 상관 관계의 공간적 분포도 확인할 수 있다.

```python
import plotly.graph_objects as go

trace=go.Splom(dimensions=[dict(label='string-1',
                                values=X1),
                           dict(label='string-2',
                                values=X2),
                           .
                           .
                           .
                           dict(label='string-n',
                                values=Xn)],
                           ....
               )
```
