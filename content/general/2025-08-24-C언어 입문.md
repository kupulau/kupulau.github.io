파이썬을 모국어로 배우고 C를 제2외국어로 배우게 된 입장에서 C언어를 공부하는 방법을 연구한다.

## C언어 기본 구조
```cpp
#include <cstdio>
 
int main() {
    printf("Hello World!");
    return 0;
}

```
- 전처리기(preprocessor) 지시어
C는 전처리기 지시어라고 해서 프로그램을 컴파일하기 전, 표준 라이브러리 코드를 갖다 쓰도록 하는 지시어를 프로그램의 가장 앞에 선언한다. 위의 코드 예시에서는 `cstudio`라는 표준 라이브러리 코드를 가져다 쓰도록 하고 있다. (`import math`처럼 파이썬 코드 가장 처음에 라이브러리들을 import 해오는 것과 비슷한 개념인 듯) `cstudio`를 가져오면 `printf()`와 같은 출력 함수를 사용할 수 있다.

- `main`
프로그램을 정의한다. `main` 앞에는 프로그램이 출력하는 데이터의 타입을 정의한다. 위의 코드 예시에서는 `int` (정수)를 반환하도록 하고 있다. 중괄호 (`{` `}`)를 이용해 프로그램의 본문을 감싸고, 이 안에 실행할 코드들을 작성한다. 하나의 명령어(statement)가 끝나면 세미콜론(`;`)으로 명령어를 종료해야 한다. 이는 파이썬에서 줄바꿈으로 명령을 구분하는 것과 대조된다. 프로그램의 마지막에는 보통 `return 0;`를 작성하여 프로그램이 정상 종료 되었음을 운영체제에 알린다. 

- 주석
  - 한 줄 주석 : `//주석`
  - 여러 줄 주석 : `/* 여러 줄 주석*/`

## C++ 입출력 방식
파이썬은 단순히 `input()`과 `print()`로 입력과 출력을 할 수 있지만 C++은 입출력 방식이 다양하다.

### 1. iostream
C++의 표준 입출력 헤더파일이다.

```cpp
#include <iostream>
 
main() {
	int a;
	std::cin >> a;	// 입력
	std::cout << a;	// 출력
}
```

### 2. stdio.h
C의 표준 라이브러리 헤더 파일을 포함시켜 C에서의 함수들을 사용할 수 있게 한다.
```cpp
#include <stdio.h>
 
main() {
	int a;
	scanf("%d", &a);	// 입력
	printf("%d", a);	// 출력
}
```

### 3. cstdio
stdio.h와 비슷하다. C언어의 표준 라이브러리를 namespace 안에서도 사용할 수 있도록 한 것이다. 
```cpp
#include <cstdio>
 
main() {
	int a;
	scanf("%d", &a);	// 입력	std::scanf 도 가능함
	printf("%d", a);	// 출력	std::printf 도 가능함
}
```
